# Nuvia para Linux (apt)

Repositorio apt de [Nuvia](https://nuviasoftware.com) para Ubuntu y Debian (amd64).

```sh
curl -fsSL https://novasofttechnologiescorp.github.io/nuvia-apt/instalar.sh | sudo sh
sudo apt install nuvia
```

Las actualizaciones llegan con `sudo apt upgrade`. Lo publica el workflow `linux-deb` del repo de la app; no se edita a mano.
